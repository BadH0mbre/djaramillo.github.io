Setting Up a Virtual Machine

A walkthrough for creating a Windows Server 2022 virtual machine in VMware Workstation Pro 17 and configuring Active Directory for homelab practice.

Project Overview

This homelab project focuses on setting up a Virtual Machine (VM) using VMware Workstation Pro 17 in order to gain hands-on experience with Windows Server 2022 and Active Directory.

Host PC Specifications

  • Windows 11
  • Ryzen 7 5800X
  • 16GB RAM
  • 2TB SSD

Creating the Virtual Machine

Step 1

Open VMware Workstation Pro 17 and click Create a New Virtual Machine. Choose the Typical installation type.

Step 2

Select I will install the operating system later.

Under Guest Operating System, choose:

  • Microsoft Windows
  • Windows Server 2022
Add operating system selection screenshot here
Step 3

Name the VM and choose the installation location.

For this project, the VM disk size was set to 20GB and configured to Split virtual disk into multiple files.

Step 4

Review the VM settings and finish the setup wizard.

Then open the VM settings and navigate to CD/DVD (SATA). Select Use ISO image file and choose your Windows Server 2022 ISO.

Installing Windows Server 2022

Step 5

Power on the virtual machine and boot from the ISO.

Configure the language, keyboard, and regional settings before clicking Next.

Step 6

Click Install now.

Select Windows Server 2022 Standard Evaluation Desktop Experience to install the GUI version.

Step 7

Accept the license agreement and choose the Custom installation option.

Step 8

Select the 20GB partition created earlier and begin the installation.

Step 9

Once installation is complete, create an Administrator password and log into the server.

Installing Active Directory

Step 10

Open Server Manager, click Manage, and select Add Roles and Features.

Step 11

Choose Role-based or feature-based installation.

Step 12

Select the local server from the server pool.

Step 13

Install the following roles:

  • Active Directory Domain Services
  • DNS Server
  • Remote Access
Step 14

Under Features, select Remote Server Administration Tools.

Step 15

Review the configuration and click Install.

Promoting the Server to a Domain Controller

Step 16

After installation, click Promote this server to a domain controller.

Step 17

Choose Add a new forest and enter your root domain name.

Example domain used in this project:

  • BigSky.local
Step 18

Set both the Forest Functional Level and Domain Functional Level to Windows Server 2016.

Configure a secure Directory Services Restore Mode (DSRM) password.

Step 19

Complete the prerequisites check and click Install.

Step 20

After rebooting, the login screen will display the domain name. Log in using the Administrator account.
